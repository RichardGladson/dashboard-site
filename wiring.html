How to read this board

Orientation

Columns
numbers, run horizontally. On the front, column numbers decrease left→right (e.g. row K runs K19 → K5, left to right) — this is given directly by your pinout, not assumed.
Rows
letters, run vertically. Row A is the bottom‑most used row, increasing alphabetically upward (A → Z).
Back view
mirrored left‑right from front (flip along the vertical axis). Column numbers therefore increase left→right on the back — same holes, same labels, just seen from the other side.
USB port
faces the board's left edge on the front; it therefore faces right on the back view shown here.

Build order

1.
Mount ESP32, buttons and OLED on the front, pins through‑hole.
2.
Flip board. All soldering and bridging wires happen on the back, per this diagram.
3.
Run the GND bus first (daisy‑chain, black), then power, then each signal wire.
4.
Leave column 1, rows P–W completely empty — reserved for the RFID module footprint.

RFID — pinout reserved, not wired

Per your instruction, the RFID reader is not wired into this build. Column 1, rows P1–W1, stays empty on the board. Below is the GPIO assignment reserved for it on the ESP32 header, so nothing else claims these pins later. Three of its SPI lines are unchanged from the repo's original pindefs.h; only SS and RST had to move because OLED now owns GPIO21/22.
